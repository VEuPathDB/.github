# VEuPathDB

The **Eukaryotic Pathogen, Vector & Host Informatics Resource** — a Bioinformatics Resource Center providing
integrated genomic, functional, and population data for eukaryotic pathogens, invertebrate vectors of disease,
and their hosts.

🌐 [veupathdb.org](https://veupathdb.org)

## Resources

| Site | Focus |
|------|-------|
| [AmoebaDB](https://amoebadb.org) | Amoebozoa |
| [CryptoDB](https://cryptodb.org) | *Cryptosporidium* and related apicomplexans |
| [FungiDB](https://fungidb.org) | Fungi and oomycetes |
| [GiardiaDB](https://giardiadb.org) | *Giardia* and diplomonads |
| [MicrosporidiaDB](https://microsporidiadb.org) | Microsporidia |
| [PiroplasmaDB](https://piroplasmadb.org) | *Babesia* and *Theileria* |
| [PlasmoDB](https://plasmodb.org) | *Plasmodium* |
| [ToxoDB](https://toxodb.org) | *Toxoplasma* and related coccidians |
| [TrichDB](https://trichdb.org) | *Trichomonas* |
| [TriTrypDB](https://tritrypdb.org) | Kinetoplastids |
| [VectorBase](https://vectorbase.org) | Invertebrate vectors of human pathogens |
| [HostDB](https://hostdb.org) | Host responses to infection |
| [OrthoMCL](https://orthomcl.org) | Ortholog groups across the tree of life |
| [ClinEpiDB](https://clinepidb.org) | Clinical epidemiology studies |
| [MicrobiomeDB](https://microbiomedb.org) | Microbiome studies |

## In this organization

- **Websites and services** — the WDK-based websites, web services, and data APIs behind the resources above
- **Data loading workflows** — `*-nextflow` repositories implement the analysis pipelines used to build each release
- **Shared tooling** — reusable CI workflows live in [VEuPathDB/.github](https://github.com/VEuPathDB/.github)
